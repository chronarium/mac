# Chronarium

Chronarium is a history timeline app for Mac. It runs on Apple silicon and Intel Macs with macOS 13 or later, and it works without an internet connection. Places, themes and people each get their own lane on one shared time axis, so Rome and Han China sit side by side, and any event or period opens into a concept map of its people, causes and consequences.

https://chronarium.app/?utm_source=github-readme

## Install

1. Download the DMG from https://chronarium.app.
2. Open it.
3. Drag Chronarium to Applications.
4. Open Chronarium from Applications. Updates install automatically from there.

## Requirements

- macOS 13 or later
- Apple silicon or Intel
